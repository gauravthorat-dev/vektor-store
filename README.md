# Vektor Store 🛍️

Vektor Store is a full-stack e-commerce web application built using Python Flask and MySQL.

## Features
- Product listing with filters
- Product detail page
- Add to cart functionality
- Checkout system (COD / UPI)
- User dashboard & order tracking
- Admin panel

## Tech Stack
- Python (Flask)
- MySQL
- HTML, CSS, JavaScript
